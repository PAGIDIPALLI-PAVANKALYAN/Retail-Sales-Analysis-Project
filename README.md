# AI-Assisted Retail Sales Data Analysis

## Project Overview
An end-to-end retail sales analytics project focused on analyzing transactional data, identifying business trends, evaluating profitability, and generating actionable business insights using Excel, Python, MySQL, and Power BI.

## Tools & Technologies
- **Microsoft Excel:** Data cleaning, missing-value handling, duplicate removal, data validation.
- **Python:** Pandas, NumPy, Matplotlib, Seaborn, exploratory data analysis.
- **MySQL:** Data extraction, joins, aggregations, CTEs, subqueries, monthly analysis, and business KPIs.
- **Power BI:** Interactive dashboards, KPI cards, DAX measures, and business reporting.

## Project Workflow
1. Dataset inspection and data understanding.
2. Data cleaning and preprocessing in Excel.
3. Exploratory Data Analysis using Python.
4. Database analysis using MySQL.
5. Customer and product performance analysis.
6. Monthly revenue and profitability analysis.
7. Year-over-Year performance comparison.
8. Interactive dashboard development in Power BI.
9. Business insights and recommendations.
