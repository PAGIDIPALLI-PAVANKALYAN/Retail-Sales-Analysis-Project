# AI Usage Documentation

## Project: Retail Sales Business Analysis

### 1. Overview

Artificial Intelligence tools were used as an analytical assistant throughout the retail sales analysis project to improve productivity, support data validation, generate analytical queries, and interpret business results.

### 2. AI-Assisted Data Cleaning – Excel

AI assistance was used for:
- Identifying missing values and duplicate records.
- Developing Excel formulas such as XLOOKUP.
- Understanding data inconsistencies.
- Supporting data validation and cleaning decisions.
- Preparing Pivot Tables and Pivot Charts.

### 3. AI-Assisted Python Analysis

AI assistance supported:
- Pandas and NumPy operations.
- Missing-value analysis.
- Data type validation.
- Exploratory Data Analysis (EDA).
- KPI calculations.
- Generating analytical code and troubleshooting errors.

### 4. AI-Assisted SQL Analysis

AI assistance supported:
- Generating SQL queries.
- Understanding JOIN operations.
- Using GROUP BY and aggregate functions.
- Customer and product performance analysis.
- Monthly revenue analysis.
- Window functions and business KPI calculations.

### 5. AI-Assisted Power BI

AI assistance supported:
- DAX formula development.
- KPI calculations.
- Power Query data preparation.
- Dashboard design and visualization selection.
- Business performance interpretation.

### 6. Business Insights

AI assistance was used to help interpret analytical results and prepare business recommendations based on actual project outputs.

### 7. Human Validation

All generated formulas, queries, calculations, and analytical outputs were reviewed and validated against the project dataset.

AI was used as an assistance tool. Data processing, execution, result verification, and analytical decisions were performed as part of the project workflow.

### 8. Tools Used

- ChatGPT – AI-assisted analytical guidance.
- Microsoft Excel – Data cleaning and Pivot Table analysis.
- Python – Pandas, NumPy and EDA.
- MySQL – SQL-based business analysis.
- Power BI – Interactive business dashboards.

### 9. Conclusion

AI assistance helped improve the efficiency of the retail sales analytics workflow, while analytical tools were used to process, validate, visualize, and interpret the actual business data.
